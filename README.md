# 卓易霆 Tim Cho · Portfolio

一頁式個人網站（HTML / CSS / JS），可部署至 GitHub Pages。

## 本機預覽

```bash
python3 -m http.server 8080
```

開啟 http://localhost:8080

## 主要內容

| 路徑                           | 說明               |
| ------------------------------ | ------------------ |
| `index.html`                 | 單頁結構           |
| `styles.css` / `script.js` | 樣式與互動         |
| `data/gallery.json`          | 作品與合照         |
| `data/awards.json`           | 獎項               |
| `data/lectures.json`         | 講義摘要           |
| `assets/`                    | 肖像、作品圖、合照 |
| `lectures/`                  | 公開 PDF           |

部署步驟見上一層 `個人網頁部署github.md`。
